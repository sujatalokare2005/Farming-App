# Farming-App
🌾 Project Title: AgroMart – Field Bound Services
📱 Project Type: Krushi Seva Mobile Application (Marathi)
🏡 Target Users: Rural community & local shopkeepers

Proud to share our project AgroMart – Field Bound Services, a Marathi-based Krushi Seva App specially designed to support rural customers by providing agricultural products directly at their doorstep.

This is a sponsorship-based project, developed to solve real-world agricultural needs and support rural digitalization.

---

🔧 Project Overview

Our application consists of two panels:

👨‍💼 Admin Panel

• Add new agricultural products

• Update product details

• Delete products

• View product list

• Receive notifications when a customer places an order


👥 Customer Panel

• View all products added by admin

• Check product image, price & description

• Add address for delivery

• Place orders and track the status

• Shopkeeper receives order details instantly


This project aims to bridge the gap between rural customers and agricultural shops, promoting digital access to essential products.
